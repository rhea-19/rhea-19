## Featured projects

### [CredentialGate](https://github.com/rhea-19/credentialgate)
A synthetic-data prototype exploring trust boundaries for AI-facing applications. It uses a real **Model Context Protocol (MCP)** interface in front of a separate credential service with signed provider/report associations, scoped authorization, independent artifact verification, and auditable access decisions.

### [Report Genie](https://github.com/rhea-19/Report-Genie)
Healthcare document-intelligence application that extracts structured information from medical PDFs, retrieves relevant context, and generates grounded report explanations and Q&A.

### [Hybrid Self-RAG](https://github.com/rhea-19/Hybrid-Self-RAG)
Retrieval-augmented generation with external evidence validation and self-reflection to improve factual reliability and reduce unsupported claims.

### [E-commerce Microservices Application](https://github.com/rhea-19/E-commerce-microservices-application)
Backend microservices project focused on service decomposition, API-driven communication, and distributed application design.

### [Custom x86 OS](https://github.com/rhea-19/Custom-x86-OS)
Low-level systems project exploring operating-system internals and x86 development.
